RazeDll
    Benjamin Green <benjamin@lh.co.nz>
    v1.0 - 23 June 2001
    http://www.lh.co.nz/

RazeDll is a simple encapsulation of Raze (the excellent Z80
emulator) as a DLL. This should allow straightforward use of
Raze from any Windows compiler.

Raze function definitions for Borland Delphi are included. Note
that the dll isn't delphi-specific in any way; however delphi
compatibility was the reason for creating razedll in the first
place.

Running make.bat should rebuild everything if you feel the need
to modify the source. Otherwise, the supplied raze.dll should
be all you need.
